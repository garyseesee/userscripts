# Userscripts

个人 Tampermonkey 脚本。

## RawINU 广告清理与规则记忆

适用于 Chrome + Tampermonkey，在 `rawinu.com`、`nihonkuni.com` 及各自子域名运行。为保留已有安装与规则，脚本名称仍为“RawINU 广告清理与规则记忆”；页面面板会显示当前网站名称。

**[安装 / 更新脚本](https://raw.githubusercontent.com/garyseesee/userscripts/main/rawinu-ad-cleaner.user.js)**

打开上面的链接，在 Tampermonkey 的安装页面确认。如果浏览器显示源码，可将全部代码复制到 Tampermonkey 的“添加新脚本”编辑器中，替换默认内容并保存。刷新支持的网站后，右下角出现“广告清理”按钮。

已经安装本地 v1.0.0 的用户：从上述链接更新，或在原脚本的编辑页面粘贴新版全部内容。请保留脚本名称与 namespace，以便保留设置和点选规则。

- 自动清理已知广告容器，并观察动态新增广告；v1.0.2 增加悬浮通知、宝箱、礼物和插屏广告的共同容器规则。
- 限制已知广告弹窗和站外脚本弹窗，包括借用空白框架窗口、提交隐藏表单的绕过方式；正常功能受影响时可以关闭严格限制。
- 清理面板的点击与网页广告监听器隔离，避免按钮被广告脚本吞掉。
- 点击“标记漏网广告”，选中广告后“隐藏并记住选区”。
- 支持撤销最后一条规则，以及暂停并恢复被隐藏的页面元素。
- 规则保存在本机；没有稳定特征的选区只临时隐藏。
- 诊断由用户主动复制，不自动上传网页内容或浏览记录。

完整安装、操作与限制说明见 [使用说明](使用说明.md)。

## 自动更新

脚本通过 `@updateURL` 和 `@downloadURL` 指向本仓库 `main` 分支。后续发布提高 `@version` 后，启用自动更新的 Tampermonkey 会按照用户设置检查和下载新版，也可以手动检查更新。

这不等于广告识别逻辑会自行演化。发现新型漏拦时，可以在 [Issues](https://github.com/garyseesee/userscripts/issues) 中提供最小复现步骤；诊断信息可选，请检查后再公开提交。

## 验证与范围

v1.1.1 通过 JavaScript 语法检查和 14 组本地模拟测试，覆盖首页/章节快照、动态广告、弹窗限制、规则持久化、撤销、暂停恢复、页面路径约束、悬浮广告、空白框弹窗、隐藏表单及面板点击保护；新增 NihonKuni 实际章节的 19 张阅读图片保护、广告位清理、同站窗口判断与设置隔离验证。

2026-10-01 实际 Chrome 验证 v1.1.1：NihonKuni 反馈章节的悬浮广告与横幅已消失，面板显示隐藏 11 个广告元素；阅读和翻页点击拦住 2 次弹窗，上一章正常加载。实际结果随广告投放变化。

在实际 Chrome + Tampermonkey 中，v1.0.4 已清理反馈章节的悬浮广告；面板显示隐藏 7 个元素，阅读与翻页点击时拦住 2 次弹窗，上一章正常加载。面板按钮和重新扫描可用。

油猴脚本主要清理页面，无法保证在网络请求发出前阻止所有广告，也无法撤销已经执行的广告代码。实际效果随网站广告实现变化；每次具体版本的浏览器验证情况记录在使用说明中。

## 版本

- **1.1.1**：补充实际检查确认的嵌套横幅外层规则，停用其内部广告框。

- **1.1.0**：支持 NihonKuni，增加该站横幅和插页广告位规则、已确认广告来源；按当前网站判断同站窗口，设置和点选规则仍按主机分别保存。
- **1.0.4**：保护清理面板免受网页全局点击监听器干扰，在面板显示当前版本。
- **1.0.3**：限制空白同源 iframe 的弹窗，以及隐藏站外表单的程序化提交；补充实测广告来源。
- **1.0.2**：识别广告脚本的 `data-shb="1"` 悬浮容器，隐藏整块广告层并停用其中的 iframe，覆盖通知、宝箱、礼物及插屏；监听延迟添加的标记。
- **1.0.1**：增加 GitHub 安装和自动更新地址。
- **1.0.0**：广告清理、弹窗限制、点选记忆、撤销与诊断。
